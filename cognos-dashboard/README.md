# IBM Cognos Analytics – Technology Trends Dashboard

This project demonstrates the use of IBM Cognos Analytics to design interactive, multi-tab dashboards for analyzing technology trends and demographics.

## Dashboard Structure
The dashboard includes three tabs:
- **Current Technology Usage** – programming languages, databases, platforms, and frameworks currently used by respondents
- **Future Technology Trends** – technologies respondents want to work with in the future
- **Demographics** – age distribution, geographic distribution, and education levels

## Skills Demonstrated
- Dashboard design for non-technical audiences
- Selection of appropriate visualization types (bar, column, treemap, map, stacked bar, line)
- Visual storytelling and executive-ready reporting
- Trend and comparative analysis

## Tools Used
- IBM Cognos Analytics
- CSV-based survey dataset

## Dataset
The dashboard was created using a large survey dataset provided as part of the IBM Data Analyst Professional Certificate.  
Due to file size constraints, the raw dataset is not included in this repository.
